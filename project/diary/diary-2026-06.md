  When you open the PR into main and pull on Replit, the load sequence is:

  git pull
  npm run seed:season   # only if weeks aren't already seeded (idempotent)
  npm run seed:games    # upserts all 272 games

  seed:games is safe to re-run — it upserts on sourceGameKey, so if the NFL flexes times you just re-run fetch:schedule,
  review the JSON diff, and re-seed.

  One thing to watch on the first Replit run: the seed fails loudly if the season or any week/team is missing, so if you see
  an error it'll name exactly which seed to run first.
