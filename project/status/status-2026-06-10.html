Key Decisions (5 Most Recent)

2026-05-15
SameSite=None session cookie for Replit iframe context
The Replit preview embeds the app in an iframe; default SameSite=Lax withholds the cookie on cross-site API calls, breaking auth after login.
2026-05-15
Auto-create league member on profile setup
Anyone who can reach the app URL is trusted; pre-seeding approved records before first login creates unnecessary admin friction for v1.
2026-05-15
Four dropped regular-season weeks
League wants Yahoo-style dropped weeks; configurable per season via dropped_week_count on the seasons row (default: 4).
2026-05-15
Per-game pick reveal (not whole-week)
A Monday night pick should stay hidden until that game starts — granular per-game reveal is fairer than unlocking the whole week at once.
2026-05-15
Derived standings from pick scores (not a maintained table)
Standings should be reproducible from picks, results, scoring rules, and dropped-week config — not from a manually maintained source-of-truth table.
