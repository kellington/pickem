Key Decisions (5 Most Recent)

2026-05-15
Auto-create league member on profile setup
Anyone who can reach the app URL is trusted; pre-seeding approved records before first login creates unnecessary admin friction for v1.
2026-05-15
SameSite=None session cookie for Replit iframe context
The Replit preview embeds the app in an iframe; default SameSite=Lax witholds the cookie on cross-site API calls, breaking auth.
2026-05-15
Framework: Express + Vite + Drizzle ORM + Tailwind v4
Replit Agent selected this stack during scaffold as the best fit for Replit Auth, managed PostgreSQL, and the private league's simple needs.
2026-05-15
Replit Agent handoff blueprint before import
Documented the approved v1 data model in REPLIT_AGENT_HANDOFF.md so the agent could scaffold without re-deciding product fundamentals.
2026-05-15
Derived standings from pick scores (not a maintained table)
Standings should be reproducible from picks, results, scoring rules, and dropped-week config — not from a manually maintained source-of-truth table.
